# Sensory Modalities Reference

A taxonomy of sensory modalities organized by stimulus type, with receptor mechanisms, encoded features, and scale-dependent properties (range, medium-dependence, etc).

---

## 1. Chemical

### Olfaction

| Feature          | Description                                                                |
| ---------------- | -------------------------------------------------------------------------- |
| Identity         | Molecular structure/shape, combinatorial coding across many receptor types |
| Intensity        | Concentration of odorant                                                   |
| Temporal pattern | Sniffing dynamics, onset/offset — also used for localization               |
| Spatial gradient | Trail-following, stereo-olfaction (two nostrils/antennae)                  |
| Hedonic valence  | Pleasant/aversive, often innate                                            |

**Range:** near to far field, medium-dependent (air vs water carries different molecule classes), medium features like turbulance and other sensitivity features

### Gustation

| Feature          | Description                                   |
| ---------------- | --------------------------------------------- |
| Category         | Sweet, sour, salty, bitter, umami, fat/kokumi |
| Concentration    | Intensity of taste                            |
| Temporal profile | Onset, lingering aftertaste                   |
| Location         | Weak in humans, stronger in some species      |

**Range:** contact only

### Chemesthesis (common chemical sense)

| Feature   | Description                                             |
| --------- | ------------------------------------------------------- |
| Intensity | Degree of irritation                                    |
| Quality   | Burning (capsaicin), cooling (menthol), stinging (CO2)  |
| Location  | Where on body/mucosa                                    |

**Range:** contact only; distinct pathway from taste/smell (trigeminal-type free nerve endings)

### Osmoreception

|Feature|Description|
|---|---|
|Fluid osmolarity|Blood/extracellular concentration|
|Rate of change|Detected via cell swelling/shrinking|

## 2. Mechanosensory

### Tactile

| Feature        | Description                                                      |
| -------------- | ---------------------------------------------------------------- |
| Location       | Spatial position on body surface                                 |
| Pressure/force | Light touch vs deep pressure (Merkel vs Pacinian receptors)      |
| Vibration      | Frequency + amplitude (Pacinian = high-freq, Meissner = lower)   |
| Texture        | Fine spatial detail, often inferred from vibration during motion |
| Motion/flutter | Direction and speed across skin                                  |
| Shape          | Integration across multiple contact points                       |
| Stretch        | Skin deformation, distinct from point pressure                   |
| Pain overlap   | Sharp vs dull, distinct fiber types                              |


**Range:** contact only; resolution scales with receptor density (fingertip vs back)

### Auditory

| Feature            | Description                                            |
| ------------------ | ------------------------------------------------------ |
| Frequency/pitch    | Range varies hugely by species (infrasound–ultrasound) |
| Amplitude/loudness | Sound pressure level                                   |
| Timbre             | Harmonic complexity, source identification             |
| Location           | Interaural time/level differences, pinna filtering     |
| Temporal pattern   | Rhythm, onset/offset, duration                         |
| Distance           | Loudness, reverberation, high-freq attenuation         |

**Range:** far-field once past a few wavelengths; strongly medium-dependent

### Vestibular

|Feature|Description|
|---|---|
|Linear acceleration|Otolith organs (utricle, saccule)|
|Angular acceleration|Semicircular canals|
|Head tilt|Relative to gravity|
|Dynamic vs static|Separate components for movement vs steady position|

**Range:** internal; developmentally coupled to auditory system (shared hair-cell mechanism)
Note: Graviception is part of vestibular in animals
### Proprioception

|Feature|Description|
|---|---|
|Joint angle/position|Static limb configuration|
|Muscle length/stretch rate|Muscle spindles|
|Muscle tension/force|Golgi tendon organs|
|Limb velocity|Rate of movement|
|Effort/motor sense|Efference copy contribution|

**Range:** internal only

### Lateral line (fish, amphibians)

|Feature|Description|
|---|---|
|Flow direction/velocity|Water displacement|
|Pressure gradients|From nearby moving objects|
|Source localization|Near-field only|
|Self vs external flow|Distinguishing own motion from environment|

**Range:** near-field, roughly one to two body-lengths — key scale limit

### Baroreception

|Feature|Description|
|---|---|
|Absolute pressure|Blood pressure or atmospheric|
|Rate of change|Trend detection|

**Range:** internal (blood) or ambient (atmospheric)

## 3. Electric

### Passive electroreception

|Feature|Description|
|---|---|
|Field strength|Ambient bioelectric fields|
|Source location|Array of receptors across body|
|Frequency sensitivity|Distinguishing biological vs geological noise|

**Range:** very short, e.g. ampullae of Lorenzini in sharks/rays; used in murky water

### Active electroreception

|Feature|Description|
|---|---|
|Object distance|Via field distortion|
|Object shape/size|Distortion pattern of self-generated field|
|Object material|Conductivity vs capacitance (prey vs rock)|
|Relative motion|Of nearby objects|

**Range:** scales with field strength and water conductivity; "electrolocation" in weakly electric fish

## 4. Magnetic

### Radical-pair (compass) mechanism

|Feature|Description|
|---|---|
|Inclination angle|Direction toward pole, not true polarity|
|Light-dependence|Often functional only at specific wavelengths, cryptochrome-based|

**Range:** whole-body, directional only (birds, possibly insects)

### Magnetite-based mechanism

|Feature|Description|
|---|---|
|Field intensity|Possible positional "map" cue|
|Polarity|True north/south|

**Range:** biomineral particles; proposed in birds, some fish, magnetotactic bacteria

### Electromagnetic induction (elasmobranchs)

|Feature|Description|
|---|---|
|Field detection|Indirect, via electroreceptive system while swimming|

## 5. Electromagnetic (light-based)

### Vision

|Feature|Description|
|---|---|
|Wavelength/color|Set by number of opsin types (humans: 3, mantis shrimp: 12+)|
|Intensity/brightness|Light level|
|Spatial resolution|Acuity — eye spot to compound eye to camera eye|
|Motion|Direction/speed, sometimes a dedicated fast pathway|
|Depth/distance|Binocular disparity, motion parallax, focus cues|
|Contrast|Edge/luminance differences|
|Polarization|In species with polarization-sensitive photoreceptors|
|Flicker/temporal resolution|Critical flicker fusion rate — wide range across species|

**Range:** far-field; wavelength range is the key scale variable (UV/visible/near-IR)

### Polarized light detection

|Feature|Description|
|---|---|
|Orientation|Navigation cue, invisible to humans|

**Common in:** insects, cephalopods

### Non-image-forming photoreception

|Feature|Description|
|---|---|
|Ambient light level|No image required|
|Day length/photoperiod|Circadian and seasonal entrainment|

## 6. Thermal

### Contact thermoreception

|Feature|Description|
|---|---|
|Absolute temperature|Separate warm and cold fiber populations|
|Rate of change|Often more salient than absolute level|
|Location|Where on skin|

**Range:** contact only, conduction-based

### Infrared radiant heat sensing (pit organs)

|Feature|Description|
|---|---|
|Direction/location|Near-thermal "imaging" in pit vipers|
|Intensity|Of radiated heat|
|Distance|Rough estimation|

**Range:** at a distance — genuinely different from contact thermoreception (detects radiation, not conduction); found in pit vipers, boas, pythons

## 7. Others

### Nociception (pain)

|Feature|Description|
|---|---|
|Intensity|Strength of noxious stimulus|
|Quality|Sharp/pricking (A-delta) vs dull/burning/aching (C fiber)|
|Location|Where on body|
|Duration/chronicity|Acute vs persistent signaling, different pathways|

**Note:** triggering stimulus can be chemical, mechanical, or thermal — pain is often treated as its own modality due to dedicated polymodal receptors

### Interoception

|Feature|Description|
|---|---|
|Heart rate/cardiac signals|Cardiovascular state|
|Respiratory drive|CO2/O2 chemosensing|
|Gut distension/fullness|Digestive state|
|Blood glucose|Metabolic state|
|Affective internal state|Feeds into mood/arousal|


### Hygroreception

|Feature|Description|
|---|---|
|Humidity level|Absolute moisture|
|Rate of change|Separate moist/dry cell types in some insects|
